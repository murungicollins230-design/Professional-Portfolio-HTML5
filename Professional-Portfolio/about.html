Technical terms we know

HTML
Hyper Text Markup Language, this is the code that gives a web page its structure and content.
CSS
Cascading Style Sheets used to control the colours, fonts and layout of the page.
Semantic HTML
Using tags like header, nav and article that describe the meaning of content which helps screen readers and search engines.
Responsive design
Building pages that adjust to different screen sizes, such as phones and laptops.
